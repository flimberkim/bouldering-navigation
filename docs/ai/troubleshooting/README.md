# troubleshooting/ — 문제 해결 사례 로그

> **적용 범위**: 실제로 겪었던 버그/장애/막힘 상황과 그 원인·해결을 파일 1개로 기록하는 곳.

## 언제 여기에 기록하는가

- 원인을 찾는 데 시간이 걸렸거나, 다시 겪을 수 있는 문제를 해결했을 때.
- "왜 안 되지?"로 시작해서 원인을 알아낸 뒤에야 고칠 수 있었던 문제일 때.

단순 오타 수정이나 원인이 자명한 버그는 기록하지 않는다.

## 파일명 규칙

`YYYY-MM-DD-짧은-증상-kebab-case.md`

## 항목 템플릿

```markdown
# {증상}

- 날짜: YYYY-MM-DD
- 관련 커밋: {짧은 해시} {커밋 메시지 첫 줄}

## 증상

## 원인

## 해결

## 재발 방지를 위해 확인할 것

## 관련 문서
```
